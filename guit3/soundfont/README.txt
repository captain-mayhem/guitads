The General MIDI soundfont guit3's MIDI player (tadsmidi.cpp, TinySoundFont)
plays MIDI music with.  It is copied next to the executable as
soundfont/TimGM6mb.sf2 and, on the web, packaged into the virtual file system
at the same path - see guit3/CMakeLists.txt.  Replacing the file with another
General MIDI .sf2 of the same name changes the instruments.
